This project relates to theorycrafting the detection engineering and some of the security work for a non-existent Managed Security Services Provider, "Fake-MSSP".

This project folder is expected to grow over time, as I return to the lab and add extra workloads to it. The aim of this project is to simulate doing part-time work for Fake-MSSP as a contractor.


Project Phases:

Phase1- Scoping the IT infrastructure and environment. Determine business needs and initial risk appetites. Building a baseline of current security operations and incident response/detection.

Phase2- Building out telemetry and associated log infrastructure. Implementing processes for an ISMS and internal escalation pathways for incident response. Creating a change management board and security committee to assist with implementation of future changes.

Phase3- Implementing detection of 10 of the most common attack vectors using the Mitre Att&ck Matrix. Implementing processes to allow for regular review of common attack vectors.

Phase4- Fine-tuning alarm noise. Implementation of Vulnerability-management systems and processes to enforce software updates.
